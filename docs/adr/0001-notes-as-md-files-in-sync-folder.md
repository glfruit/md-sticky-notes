# 便签即同步文件夹里的 .md 文件

每张便签持久化为同步文件夹里的一个 `.md` 文件（YAML frontmatter + 正文），不引入私有数据库，也不自建云服务；多机同步完全交给用户已有的云盘客户端（Dropbox / iCloud Drive / 坚果云）。这是产品的核心身份：数据归用户所有、格式开放、无供应商锁定。

## Considered Options

- **自有云同步**（账号 + 服务端）：个人开发者养不起基础设施，且与「数据自主」的产品理念冲突。
- **SQLite 等本地数据库**：用户不可见、无法用其他编辑器查看；数据库单文件经云盘同步极易损坏。

## Consequences

- 同一便签文件被两台机器同时修改时后写覆盖，无合并——有意接受（便签是单人短内容场景）。
- 元数据表达受 frontmatter 格式约束，字段演进需保持向后兼容。
